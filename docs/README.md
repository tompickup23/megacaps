## ❓ FAQ

### Q: Should I start with POD or manufacturing?
**A:** **Always start with POD (Phase 1).** It's capital-light, risk-free, and proves demand. Once you've validated designs and sold 100+ units, move to manufacturing.

### Q: Which supplier should I use first?
**A:** **Printful for POD** (proven quality, easiest setup) **→ Result Headwear for manufacturing** (UK-based, good value, responsive).

### Q: How long does Phase 1 take?
**A:** 4–8 weeks. This includes sample sourcing, product launch, and initial sales validation.

### Q: What's the minimum I should order in Phase 2?
**A:** 50–100 units as a test. Don't commit to 500 units until you've proven demand with the supplier.

### Q: Can I use multiple suppliers?
**A:** **Absolutely.** In fact, it's recommended. Use Printful for design validation, Result Headwear for UK manufacturing, Atlantis for premium drops. Diversification reduces risk.

### Q: How much capital do I need to start?
**A:** Phase 1: £500–£1,000 (very low risk). Phase 2: £2,000–£4,000 (inventory + COGS). Don't start Phase 2 until Phase 1 is validated.

### Q: What if a supplier doesn't respond?
**A:** Wait 72 hours, send one follow-up. If still no response, move to backup supplier. Don't waste time on non-responsive partners.

### Q: How do I negotiate trade accounts?
**A:** See OUTREACH.md → Template 6. Key points: show commitment (future volume), ask for percentage discounts (5–10%), discuss payment terms. Suppliers prefer reliable repeat customers.

### Q: What's a reasonable lead time?
**A:** POD: 2–10 days. UK Manufacturer: 5–7 days (stock) / 2–4 weeks (custom). EU Premium: 3–4 weeks. Plan accordingly.
